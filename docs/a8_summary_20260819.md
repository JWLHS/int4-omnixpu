# A8（W4A8）完成度汇总报告 — 2026-08-19

## 一、结论

| 项 | 状态 |
|---|---|
| wa4 格式 a8（QW/kr2，gs=64） | ✅ 可用（同 seed 与 a16 corr 0.95-0.998，无黑图） |
| tint4 格式 a8（gs<=64） | ✅ 可用（Boogu-Edit corr 0.9997，近乎无损） |
| tint4 格式 a8（gs>64，QW/kr2 为 gs=128） | ⚠️ A770 的 oneDNN s8u4 不支持 → 自动回退 w4a16（安全） |
| 显存收益（图像 1024²/1600²） | ❌ 结构性无收益（int4 权重 10.7GB 是地板，激活收益不可见） |
| 速度 | a8 稳态比 a16 慢约 1.5-2.4×（非优先项） |
| 回退阶梯 | ✅ w4a4（预留）→ w4a8 → w4a16 → python/torchao |

## 二、根因（QW 无法用 a8）

1. **wa4 黑图**：s8u4 kernel 的 f32 scale + f32 dst 修复前，QW 规模数值溢出 →
   黑图/黑点。已在 01 kernel 修复，实测同 seed corr 0.955-0.998。
2. **tint4 黑图**：旧转换路径权重语义错误（xor 处理）→ 黑图；且
   **A770 上 oneDNN s8u4（s8 激活）primitive 对权重 gs>64 直接崩溃**（pd 创建
   access violation），tint4 QW/kr2 均为 gs=128。
3. **修复**：tint4-a8 = raw 权重（不异或）+ 现有 onednn_s8u4_gemm（标量 zp=8）
   + per-block zp 修正项 `(8-zp)*scale` 小矩阵外积；gs>64 加载时自动回退 a16。

## 四、代码落点

- kernel：**无需新增 a8 算子**（tint4-a8 复用 onednn_s8u4_gemm）；PR 仅含
  tint4 原生 op（onednn_int4_gemm_tint4）+ s8u4 f32-scale 修复。
- 插件（int4-omnixpu，commit `7d4b912`）：
  - tint4-a8 raw 权重 + 修正项（`_prepare` / forward correction 分支）
  - gs>64 加载回退（`_index_int4_from_sd` / 加载处警告）
  - 通用回退链 `_resolve_backend`（w4a4→w4a8→w4a16）
  - 激活量化分组 src/wei 解耦（`_act_gs`）
